# Historical task evidence

This directory preserves earlier per-slice contracts, migration evidence,
implementation notes and reviews. The files are retained at their original paths
because ADRs, migration records and reference tooling cite them.

These are **historical records**, not the current backlog or a required artifact
set for new work. Old phase gates, review counts and broad parity targets do not
override [AGENTS.md](../AGENTS.md), [CONTRIBUTING.md](../CONTRIBUTING.md),
[SPEC.md](../SPEC.md) or the [current roadmap](../docs/TABDAT_RUST_PORT_ROADMAP.md).

For current development, use focused tests and concise PR evidence. Consult a
specific task folder only when its contract or provenance is relevant; do not
create another folder merely to mirror this historical layout.
