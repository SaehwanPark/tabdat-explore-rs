# ADR NNNN: Decision title

- Status: Proposed | Accepted | Superseded (choose one)
- Scope: Bounded decision and affected contracts

## Context

Evidence, constraints, source revisions, and the problem requiring a decision.

## Decision

Tradeoffs, risks, tests/benchmarks, license/redistribution review where applicable,
