# Robust AR confidence sets with two excluded instruments

## Implemented contract

After an HC1 or one-way CR1 2SLS fit with exactly one endogenous regressor and
two excluded instruments, `estat ar, ci [level(95)]` inverts the joint
auxiliary-regression Wald test. Included exogenous coefficients remain
unrestricted. The confidence set uses an asymptotic chi-square(2) reference.
The two-instrument result has its own JSON type and reports both instrument
names; the one-instrument robust result and its JSON shape remain unchanged.

The HC1 correction is N/(N−K_aux). CR1 uses
G/(G−1)*(N−1)/(N−K_aux), with K_aux counting the intercept, included controls
and both excluded instruments. The auxiliary residuals supply row or cluster
scores. The quartic boundary is isolated by recursively finding derivative
roots and bisecting each monotone segment. The code checks the sign of every
segment, verifies each finite endpoint against the direct AR Wald test, and
checks relative score-meat conditioning over the real line. It uses no finite
beta grid. Repeated/ambiguous roots, rank failure, singular or ill-conditioned
score covariance and numerical-range failures are explicit errors.

## Independent evidence

The deterministic fixture and Base R reference are generated by
[`robust_ar_multi_ci_reference.R`](../../crates/tabdat-stats/tests/fixtures/robust_ar_multi_ci_reference.R).
The data have 20 rows, one included control and ten two-row clusters. The
auxiliary parameter count is 4, residual DF is 16, and the 95% chi-square(2)
critical value is 5.99146454710798.

| Design | Covariance | Correction | Confidence set |
| --- | --- | ---: | --- |
| multiple | HC1 | 1.25 | (-inf, 0.0628690191316964] ∪ [0.715734989894617, 1.07279148560636] ∪ [2.1595204517105, +inf) |
| multiple | CR1, 10 groups | 1.31944444444444 | (-inf, 0.154198964682854] ∪ [0.573634185761531, +inf) |
| all-real | HC1 | 1.25 | (-inf, +inf) |
| all-real | CR1, 10 groups | 1.31944444444444 | (-inf, +inf) |

Base R `lm.fit`, explicit score sandwiches and `polyroot` supply the reference
intervals and direct Wald statistics at interior/exterior probes. Rust tests
compare every endpoint and probe, check HC1/CR1 metadata, no-intercept behavior,
instrument rescaling, rank and cluster failures, singular auxiliary residuals,
root degree reduction, repeated/near-coincident roots, state retention, and
JSON/text workflows. The three-component HC1 example has two rays and a bounded
interval; a quartic with simple roots cannot produce three bounded intervals.

These are synthetic method checks, not a Cameron–Trivedi illustration, a
coverage simulation, or evidence that instruments are valid. HC1 assumes
independent rows. CR1 assumes independent groups and many-group asymptotics, with
no finite-sample or few-cluster guarantee. More than two excluded instruments,
multiple endogenous regressors, robust projection and HAC/survey covariance
remain unsupported in this slice.
