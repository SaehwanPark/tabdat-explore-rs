# NB2 fixed offsets with joint dispersion inference

This native synthetic workflow fits `mu_i=exp(X_i beta+log_time_i)` and
`Var(y_i|X_i)=mu_i+alpha*mu_i^2`. `offset(log_time)` fixes its coefficient at one:
it is not a parameter or weight. The CSV contains 36 ordered synthetic rows, two
predictors, six illustrative cluster labels and a provided finite log-offset.
It is generated by the reference below, with no external data rights or
production R/Python requirement. This is method evidence, not a textbook
replication, a resolution of printed Table20.6 or a panel-model claim.

Run from this directory:

```sh
cargo run --locked --manifest-path ../../Cargo.toml -- --json -f workflow.td
# Substitute --text for terminal tables.
```

The script loads/previews the design, fits independent-row robust NB2, reports
retained continuous effects and descriptive observed/fitted count bins, predicts
current means/indices and exports `nb2_offset_predictions.csv`. Export refuses an
existing target; remove your own prior output or choose a fresh directory.
Replace `robust` with `cluster(person)` only if independence across those groups
is defensible. Omit both for distributional model-based NB2 inference.

## Statistical and state contract

- Joint complete-finite outcome/predictor/offset/group selection precedes finite
  invalid-count rejection, retaining exact source positions/order. Existing
  counts0..100000, N>K+1, full mean rank, lnalpha interior(-12,12), positive final
  undamped joint curvature and absolute convergence bounds remain unchanged.
  The offset does not increase K, LR DF or covariance corrections.
- BOTH full and null models retain the same offsets. With an intercept the NB
  null jointly refits its intercept AND dispersion; without one, mu=exp(offset)
  and dispersion is refitted. Poisson is only a starting fit, not the NB null or
  final covariance. There is no Poisson-null alpha or fixed-alpha substitution.
- Selected covariance uses the FULL joint beta/lnalpha observed inverse bread,
  with model-based, N/(N-1) independent-row or G/(G-1) grouped JOINT scores.
  Beta/log-alpha inference is normal95; alpha SE is delta-method and its interval
  exponentiates the log-alpha interval. Robust/cluster LR p/reference are absent.
- `predict ..., xb` is CURRENT X beta+offset, not X beta alone; `predict ..., n`
  exponentiates it. Current predictors and offset are required, not outcome/group
  IDs. Missing/nonfinite rows/overflowing means give NULL; finite exponential
  underflow gives zero. Bad schemas publish no column and retain the fit.
- `estat margins` holds retained X and offset values fixed, with full joint
  covariance and gradient `[beta_j*mean(mu*X)+e_j*mean(mu),0]`. No chain rule through
  offset is implied, even if the offset is also a predictor. Data edits do not
  alter retained effects/count bins; bins additionally retain original alpha and
  assume the full NB2 law, which robust covariance does not guarantee.

## Independent evidence

From the repository root:

```sh
Rscript crates/tabdat-stats/tests/fixtures/nb2_offset_reference.R
cargo test --locked -p tabdat-stats --test nb2_offset
cargo test --locked -p tabdat-runtime --test nb2_offset_contract
cargo test --locked --test cli_json_nb2_offset_contract
```

R4.6.1/MASS7.3.65 supplies starting fits polished to the full joint fixed point.
Base R dnbinom/digamma/trigamma independently supplies the likelihood, joint scores
and observed curvature; numerical differentiation checks score and curvature at
the optimum and a nearby nonzero-score point. **1,076 scalar references** span
intercept/two-predictor, no-intercept/two-predictor and intercept-only designs,
each with three covariance choices. They cover full coefficient/dispersion
inference and covariance, all means/indices, refitted null alpha/likelihood/LR,
Wald where applicable, deviance/Pearson/DF/pseudo-R2 and full delta effects.
Absolute tolerance is 1e-9 for parameter quantities/totals; tails use relative
1e-9, never an absolute small-p shortcut. Native tests also cover exact samples,
zero-offset equivalence, +1000 offset/intercept shifts, source-name provenance,
state/failure invariants and actual JSON/text script exports against R.

No exposure alias, weights/survey/multiway/few-cluster methods, factor/discrete
changes, other formal specification tests or named count reports are added.
Equivalent log-exposure preparation may use input/explicit SQL; `generate`
function calls remain unsupported. Extreme finite designs may still fail the
bounded numerical policy. Remaining count/panel/textbook requirements stay open.
