# Fixed Poisson log-mean offsets (synthetic method evidence)

This small native workflow fits `mu_i = exp(X_i beta + log_time_i)` with
`offset(log_time)`. The offset has fixed coefficient one: it is neither an
estimated regressor nor a weight. The included synthetic CSV has 36 ordered
rows, two predictors, six independent-cluster labels and a provided finite
log-offset. It is generated by the R reference below; no external data rights or
runtime R/Python dependency are involved. These are illustrative data, not a
Cameron–Trivedi replication or a claim that person/time dependence is resolved.

Run from this directory:

```sh
cargo run --locked --manifest-path ../../Cargo.toml -- --json -f workflow.td
# Use --text instead of --json for the terminal report.
```

The script loads/previews the design, fits independent-row robust Poisson,
reports retained continuous effects and descriptive observed/fitted count bins,
predicts current means and indices, and exports `poisson_offset_predictions.csv`.
It does not overwrite an existing export: choose a fresh directory or remove your
own previous output before repeating. For grouped inference, replace `robust`
with `cluster(person)` only when independence across those groups is justified.
Omit both for model-based Poisson inference (variance equals mean).

## Sample, null and interpretation

- Joint finite outcome/predictor/offset and optional group selection precedes
  finite invalid-count rejection. Source order and exact retained positions are
  preserved. Count bounds, N>K, rank and numerical-convergence rules remain the
  existing Poisson rules. The offset does not increase K, LR DF or covariance
  correction factors.
- The null retains the SAME offsets: with an intercept,
  `mu0_i = exp(offset_i) * sum(y)/sum(exp(offset))`; without one,
  `mu0_i = exp(offset_i)`. The implementation evaluates the intercept/null through
  a log-sum-exp, rather than overflowing a naive sum of exponentials.
- `predict ..., xb` includes the current offset (`X beta + offset`), and
  `predict ..., n` exponentiates that index. Both require current numeric offset
  and predictor columns but not outcome/group IDs. Missing/nonfinite rows yield
  NULL; overflowing means yield NULL, while finite negative exponential
  underflow is zero. Invalid prediction schemas fail without partial publication.
- `estat margins` is `beta_j * mean(fitted_mu)` with conditional retained-X
  delta uncertainty. Offsets are held at their retained values in derivatives
  and uncertainty, even if an offset variable is also a predictor; there is no
  chain rule through the offset. Data edits do not alter retained effects or
  `estat countprob`. Robust/cluster covariance does not guarantee the Poisson
  distribution assumed by count-probability bins; these are not formal tests.

## Independent reference and evidence

From the repository root, regenerate the synthetic input and numerical fixture:

```sh
Rscript crates/tabdat-stats/tests/fixtures/poisson_offset_reference.R
cargo test --locked -p tabdat-stats --test poisson_offset
cargo test --locked -p tabdat-runtime --test poisson_offset_contract
cargo test --locked --test cli_json_poisson_offset_contract
```

Base R 4.6.1 `glm(..., family=poisson(), offset=...)`, polished at its fixed point,
plus independent score/bread sandwich algebra validates **950 scalar quantities**
across intercept/two-predictor, no-intercept/two-predictor and intercept-only
models, each with model-based, N/(N-1) robust and G/(G-1) clustered covariance.
References include coefficients/full covariance/normal inference, all 36 means
and indices per fit, likelihood/same-offset-null/LR, Wald where applicable,
deviance/Pearson/DF/pseudo-R2, and continuous effects/full delta uncertainty.
Parameter quantities and fit totals use absolute 1e-9 tolerances; tails use
relative 1e-9, not a blanket absolute small-p tolerance. Native tests also cover
zero-offset equivalence, constant-offset/intercept shifts, invalid alignment,
joint exclusions/exact sample, current-versus-retained semantics and failed-fit/
prediction invariants. The actual script is checked through JSON and text with
identical exported data.

## Limits

Exposure shorthand, NB2 offsets, weights/survey, multiway/few-cluster inference,
factor/discrete-change effects, general count tests/lincom and named count reports
remain unimplemented. Supply a precomputed log exposure from input or explicit
SQL when appropriate; `generate` function calls are not installed. Extreme finite
offset designs can fail the bounded representability/convergence policy. This
method extension does not resolve the printed Table20.6 NB2 discrepancy or advance
any textbook illustration to validated status.
